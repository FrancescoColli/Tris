# React Tris

Un semplice gioco del Tris realizzato con React.

Il progetto è stato sviluppato durante il mio percorso di apprendimento di React, seguendo un corso e personalizzando la logica dell'applicazione.

## Funzionalità

- Due giocatori: X e O
- Evidenziazione del giocatore di turno
- Modifica dei nomi dei giocatori
- Cronologia delle mosse
- Rilevamento di vittoria e pareggio
- Pulsante per ricominciare una partita

## Tecnologie usate

- React
- JavaScript
- CSS
- Vite
